# Gesture Presentation — керування презентацією жестами

Програма показує PNG-слайди та дозволяє перемикати їх, малювати на них, стирати намальоване й змінювати колір за допомогою жестів перед вебкамерою. Розпізнавання кисті виконує **MediaPipe Hands**, зображення обробляє **OpenCV**.

## Вимоги

- **Python 3.11 або 3.12** (рекомендовано 3.11).
- Windows, macOS або Linux із графічним робочим столом.
- Вебкамера та дозвіл операційної системи на доступ до неї.
- PNG-зображення для презентації.

> Використовується `mediapipe==0.10.21`, оскільки проєкт працює зі старим API `mp.solutions.hands`. Новіші випуски MediaPipe можуть не підтримувати цей API.

## Структура проєкту

```text
gesture_presentation/
├── main.py                 # точка входу та цикл камери
├── requirements.txt        # залежності
├── README.md
├── config/
│   ├── __init__.py
│   ├── config.py           # читання YAML, налаштування та перевірки
│   └── config.yaml         # усі значення, які можна змінювати
├── core/
│   ├── __init__.py
│   ├── vision.py           # MediaPipe та координати вказівника
│   ├── gesture.py          # пальці, розпізнавання, утримання
│   ├── presentation.py     # слайди, малювання, стирання
│   └── visualize.py        # оформлення камери/індикаторів
├── slides/                 # два демо-слайди; замініть на власні PNG
└── tests/
    └── test_core.py
```

## Встановлення

1. Завантажте проєкт і відкрийте термінал у папці `gesture_presentation`.
2. Створіть віртуальне середовище **Python 3.11**:

   **macOS / Linux**

   ```bash
   python3.11 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

   **Windows (PowerShell)**

   ```powershell
   py -3.11 -m venv .venv
   .venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

   Якщо PowerShell забороняє активацію, можна виконати `.venv\Scripts\python.exe -m pip install -r requirements.txt` без активації.

3. У папці `slides/` уже є **два демонстраційні слайди**, тож проєкт можна одразу перевірити. Для власної презентації видаліть демо-файли й додайте свої PNG-слайди:

   ```text
   slides/
   ├── 01.png
   ├── 02.png
   └── 03.png
   ```

   Слайди сортуються за назвою. Різні розміри зображень автоматично приводяться до розміру першого слайда.

## Запуск

З кореневої папки проєкту:

```bash
python main.py
```

З'являться вікна **Presentation** (слайд) та **camera** (вебкамера). Для виходу натисніть **Esc** або **q**, або закрийте вікно.

## Жести

Порядок пальців: **великий, вказівний, середній, безіменний, мізинець**; `1` — випрямлений, `0` — зігнутий.

| Жест | Пальці (0/1) | Дія |
| --- | --- | --- |
| Відкрита долоня | `11111` | Почати презентацію; також очистити малюнок на поточному слайді |
| Вказівний | `01000` | Наступний слайд |
| Великий | `10000` | Попередній слайд |
| Вказівний + середній | `01100` | Малювати |
| Великий + вказівний + середній | `11100` | Наступний колір |
| Вказівний + середній + безіменний | `01110` | Стерти малюнок |

Жест треба **утримувати приблизно 1 секунду**. Команди початку, перемикання слайдів і кольору виконуються лише один раз за одне утримання. Малювання й стирання тривають, доки відповідний жест активний. Стирання повертає вихідне зображення слайда, а не зафарбовує його чорним. Індикатор біля пальця показує прогрес утримання.

## Налаштування

Усі основні параметри винесено до `config/config.yaml`. Після їх зміни перезапустіть програму.

| Параметр | Призначення |
| --- | --- |
| `slides.directory`, `slides.pattern`, `slides.scale` | Директорія, маска файлів і масштаб слайдів |
| `camera.index`, `camera.preview_width` | Номер камери (спробуйте `1`, якщо `0` не працює) та ширина прев'ю |
| `camera.mirror`, `camera.median_blur_kernel` | Дзеркальне зображення й сила медіанної фільтрації (непарне число) |
| `vision.detection_confidence`, `vision.tracking_confidence` | Пороги моделі MediaPipe |
| `vision.thumb_open_ratio`, `vision.finger_tips` | Параметри розпізнавання пальців (за замовчуванням `0.7` і `[8,12,16,20]`) |
| `pointer.crop_offset`, `pointer.crop_width` | Ділянка відеокадру, що відображається на весь слайд |
| `pointer.smoothing` | Згладжування курсора від `0` до `1` (`1` — без згладжування) |
| `gestures.hold_seconds` | Скільки секунд утримувати жест |
| `gestures.debounce_seconds` | Фільтр коротких випадкових перемикань жестів |
| `gestures.patterns` | Відповідність команди та п'яти пальців |
| `drawing.colors` | Палітра; **BGR**, а не RGB |
| `drawing.brush_size`, `drawing.eraser_radius` | Розміри пензля та гумки |
| `display.*` | Вікна, індикатор утримання, скелет і палітра |

Наприклад, щоб зменшити час утримання до 0.7 секунди:

```yaml
gestures:
  hold_seconds: 0.7
```

**Увага:** редагуйте наявний параметр у повному файлі `config.yaml`, а не замінюйте весь файл наведеним фрагментом.

## Тести

Запустіть із кореня проєкту:

```bash
python -m unittest discover -s tests -v
```

Тести перевіряють конфігурацію, таймер жестів і малювання; вебкамера для них не потрібна.

## Поширені проблеми

- **`FileNotFoundError: ... slides`** — додайте принаймні один PNG-файл у `slides/`.
- **Не відкривається камера** — надайте дозвіл у налаштуваннях ОС, закрийте Zoom/інші програми та перевірте `camera.index`.
- **`No module named 'mediapipe'`** — активуйте `.venv` і повторіть `pip install -r requirements.txt`.
- **`module 'mediapipe' has no attribute 'solutions'`** — використовуйте версію `mediapipe==0.10.21` із `requirements.txt`.
- **Не відображаються вікна** — запускайте локально на комп'ютері з графічним робочим столом, не в хмарному/headless-середовищі.
- **macOS:** дайте Terminal / Python / IDE доступ до камери у **System Settings → Privacy & Security → Camera**.

## Що було відрефакторено

- Замінено помилкові `file`/`name` на правильні `__file__`/`__name__` (у готовому коді відносні шляхи обробляє `config.py`).
- Виправлено відступи циклу обробки кадрів.
- Винесено «магічні числа» та колірні константи в YAML.
- Велику функцію `main()` розбито на невеликі функції та класи.
- Додано docstrings, обробку відсутності слайдів/камери, гарантоване звільнення ресурсів.
